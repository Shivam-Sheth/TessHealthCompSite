# Founder photos

Drop each founder's photo in this folder using these exact filenames:

- `shivam.jpg` — Shivam Sheth (CEO)
- `ananya.jpg` — Ananya Raj Girish (CPO)
- `aryaan.jpg` — Aryaan Peshoton (CTO)
- `ishita.jpg` — Ishita Kasliwal (COO)

## Specs

- **Dimensions:** 240×240px (square, 1:1). They render in 96px circles, so 240px keeps them crisp on retina screens.
- **Crop:** Center the face (head + shoulders).
- **Format:** `.jpg` preferred (keep each under ~200 KB). If you use `.png`, update the `photo` paths in `src/components/Founders.jsx`.

Until a photo is added, the card automatically falls back to the founder's initials on a teal gradient.
